# Reading Vault

用 **WorkBuddy（读书搭子）+ Obsidian + GitHub** 维护的阅读知识库。

## 数据流

| 环节 | 谁干 | 干什么 |
|------|------|--------|
| 微信读书 | 读书搭子 Skill 同步 | 划线、想法、阅读进度（数据在本机，Key 不入对话） |
| WorkBuddy | 整理生成 | 原始划线 → 结构化书籍笔记 → 索引，**人确认后才写盘** |
| Obsidian | 阅读与沉淀 | 双链、回顾、输出 |

## 目录约定

| 目录 | 放什么 |
|------|--------|
| `00-收集箱-Inbox/` | 微信读书导出的**原始划线**（不动原文） |
| `10-书目-Books/` | 每本书一页结构化笔记（用 `templates/书籍笔记.md` 起稿） |
| `90-索引-Index/` | MOC 导航页（在读 / 已读 / 主题） |
| `templates/` | 笔记模板 |
| `attachments/` | 图片等附件 |

**暂不建**：复盘、卡片目录 —— 第一份复盘/卡片产生时再建，不预建空目录。

## 硬约束

- 原始摘录与 AI 整理**分开放**：划线原文在 Inbox，整理稿在书目页，AI 建议标注来源，不写成"我的感悟"。
- 导航靠 `Cmd+O` 跳转，`[[]]` 只用于知识↔知识关联，不制造死链。
- 书目页 frontmatter 必填：`书名 / 作者 / 状态 / 来源`。
